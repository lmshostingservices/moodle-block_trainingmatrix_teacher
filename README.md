# Staff Training Dashboard Block

This free manager companion block provides a dashboard entry point to staff
training and compliance information maintained by AI Training Matrix.

## Features

- Surface staff training summaries for authorised managers.
- Provide access to the parent plugin's management and reporting tools.
- Reuse the parent plugin's training records rather than maintaining a second ledger.

## Requirements

- A compatible AI Training Matrix release, as declared in version.php.
- Moodle 4.4 or later within the declared supported range.
- Appropriate staff-management permissions.

## Installation

1. Install or update AI Training Matrix first.
2. Install block_trainingmatrix_teacher in blocks/trainingmatrix_teacher.
3. Complete Moodle's administrator upgrade screen.
4. Add the block to authorised managers' dashboards.

## Usage

Configure staff and requirements in AI Training Matrix, then use the dashboard
block to review training status. Grant management capabilities deliberately:
placing a block on a dashboard must not be used as a substitute for role setup.

## Pricing

This companion block is free. The parent plugin has its own acquisition price.
